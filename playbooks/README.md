# Playbooks (Stretch Goal — Phase 7.3)

Ansible playbooks go here. Suggested starting points:

- `wazuh-agent-linux.yml` — install/configure the Wazuh agent on Linux targets
- `pfsense-backup.yml` — pull a config backup from pfSense via its XML export API

This is what turns "I clicked through an installer" into "I can rebuild this from code" — worth doing even in minimal form for the portfolio.
